# The experiment model is a free local open-weight model served by Ollama

The project must cost nothing, so the 270-run pass uses an open-weight, tool-calling model served by Ollama on a free Colab GPU, with no API key. The default is `qwen2.5:7b`, pinned by its Ollama tag and recorded in every log line; the dry run confirms it calls tools reliably before the held-out pass. Unlike the Anthropic API (ADR 0002), a local model accepts sampling settings, so every request uses temperature 0, seed 672 and a 16,384-token context (Ollama's smaller default truncates long tool conversations silently). Runs are therefore repeatable on the same model build and hardware. Results describe one small model and may not transfer: Tsegai et al. (2026) report open-weight triage results varying widely by model, and the report states this limitation. The Anthropic adapter stays in the code, tested but optional; ADRs 0002 and 0003 apply only when it is used.
